## Starter Prompts
Copy, fill the `[brackets]`, paste into any AI assistant.

- **Product idea check:** `I want to build [idea] for [audience]. List the top 5 risks, 3 similar products, and the smallest version I can launch in 2 weeks.`
- **Build a simple app:** `I am not a programmer. Build a [type of app] that does [feature 1], [feature 2]. Explain each step in simple words.`
- **Fix an error:** `I got this error: [paste error]. Explain what it means in simple words and tell me exactly what to change.`
- **Landing page copy:** `Write a landing page for [product]: headline, 3 benefits, FAQ, and a call to action for [audience].`
- **Understand a GitHub repo:** `Explain this project like I'm a beginner: what it does, how files are organised, and one easy way I could contribute.`
